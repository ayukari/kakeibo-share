# 個人情報の扱い（案。公開の前に社長が確認）

## 集めるもの
- メールアドレスとパスワード（Supabase Auth。パスワードはハッシュで保存）
- 表示名、参加している家計簿、権限
- 家計簿の記録（金額・日付・カテゴリ・メモ・誰が払ったか・割り勘）
- 操作の履歴（誰がいつ何を変えたか。金額と権限・状態の変化だけで、メモの中身は残さない）

## 誰が見られるか
- 家計簿の記録は、その家計簿のメンバーだけ。「自分だけ」の記録は本人だけ。
- 招待コードは作ったときに 1 度だけ表示され、サーバーにはハッシュしか残らない。
- 運営者（社長）は Supabase のダッシュボードから DB を見られる。これは利用者に伝える必要がある。

## 保存場所
- Supabase（東京リージョンを推奨）。端末には、ログインのセッション（暗号化）と最後に開いた家計簿の ID だけ。
- 書き出した CSV は利用者が選んだ場所に保存され、アプリの外になる。

## 消すとき
- 記録の削除は「削除済み」にして集計から外す（同時編集と履歴のため）。完全に消すのは家計簿の削除・アカウントの削除のとき。
- アカウントを削除すると、「自分だけ」の記録は消え、グループの記録は「退会したメンバー」の名前で残る（ほかの人の精算が壊れないため）。
- 家計簿を削除すると全員から見えなくなる（DB には削除の印が付いた状態で残る。完全に消す作業は運営者が行う ［要確認: 期間の決め方］）。

## しないこと
- 広告・分析のための送信、第三者への提供はしない。
- 銀行口座・カードとの連携はしない。
