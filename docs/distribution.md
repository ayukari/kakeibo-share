# 配り方（決めるのは社長。申し込み・支払いは社長が行う）

## Android
1. いちばん安い: 署名した APK を家族・知人に直接渡す（0 円）。受け取った人は「提供元不明のアプリ」を許可して入れる。更新も手で渡す。
2. Google Play（登録 25 ドル 1 回）: 内部テスト（100 人まで）なら審査が軽く、そのまま家族用に使える。一般公開には 12 人・14 日間のクローズドテストが必要（新しい個人アカウント）。
- 署名の鍵（keystore）は社長の PC だけに置き、リポジトリに入れない。なくすと同じアプリとして更新できない。

## iOS
- Apple Developer Program（年 99 ドル）が必要。TestFlight で家族・知人に配る（ビルドは 90 日で期限切れ → 定期的に上げ直す）。
- App Store に出す場合は、プライバシーの説明（docs/privacy.md）と、アカウント削除の機能（実装済み）が審査で求められる。
- ビルドと提出はクラウドの Mac（GitHub Actions）から行える。証明書と鍵は GitHub の Secrets に入れる（社長の操作が必要）。
